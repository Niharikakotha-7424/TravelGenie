# ✈️ TravelGenie

### AI-Powered Smart Travel Planning Platform

TravelGenie is an AI-powered travel planning platform designed to make trip planning simple, personalized, and budget-friendly.

Instead of searching across multiple platforms for destinations, food, accommodation, weather, maps, activities, and travel information, users can manage their trip planning in one place.

---

## 🌍 Problem Statement

Travelers often spend a lot of time searching across different websites and applications for:

- Destinations and attractions
- Accommodation options
- Food and restaurants
- Weather information
- Travel routes
- Budget planning
- Local experiences and guides

This scattered information can make travel planning confusing and time-consuming.

---

## 💡 Our Solution

TravelGenie brings essential travel planning features together into one platform.

Users can enter their destination, travel duration, budget, interests, and preferences to create a personalized travel plan.

### Key Features

- 🤖 AI-powered travel planning
- 💰 Budget optimization
- 🗓️ Day-wise travel itinerary
- 🌦️ Real-time weather information
- 🗺️ Interactive maps
- 🚗 Road route planning
- 📍 Nearby places and attractions
- 🏨 Accommodation options
- 🍴 Food and restaurant discovery
- 🧑‍🤝‍🧑 Local guide opportunities
- ⭐ Ratings and reviews
- 💾 Save and manage trips
- 🔐 User registration and login
- 📊 Travel dashboard

---

## 🗺️ Smart Map

TravelGenie provides an interactive map where users can:

- View planned destinations
- View nearby real-world places
- See route connections
- Get road directions
- Search and filter places
- Open locations in Google Maps

The map functionality uses OpenStreetMap-based services.

---

## 🌦️ Real-Time Weather

TravelGenie integrates weather information to help users understand the conditions at their destination.

Weather information includes:

- Temperature
- Feels-like temperature
- Humidity
- Weather description

---

## 🧭 Location & Mapping Technologies

TravelGenie uses several open and real-world location services:

- **OpenStreetMap** – Geographic map data
- **Nominatim** – Location geocoding
- **Overpass API** – Nearby places and attractions
- **OSRM** – Road route calculation
- **Leaflet** – Interactive map visualization
